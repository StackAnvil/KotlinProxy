# KotlinProxy repository rules

## Language

- All application code is Kotlin. Do not add `.java` source files.
- Build logic stays in Gradle; keep the Kotlin JVM target at 17.
- The mixin compatibility level is JAVA_8 so the Java 8 build runs the same
  mixins. Avoid Java 9+ language features in mixin classes.

## Runtime patches

- Runtime patches use SpongePowered Mixin (`org.spongepowered:mixin`).
- Do not reintroduce ClassTransform or `net.lenni0451.classtransform`.
- Mixin classes live in `net.raphimc.viaproxy.injection.mixins` and are listed in
  `src/main/resources/mixins.kotlinproxy.json`.
- `@Shadow` fields need `@JvmField` and `@field:Shadow`.
- The application starts in `KotlinProxyLauncher`, which creates a child-first
  `MixinClassLoader`. The loader applies mixins while classes are defined and
  supplies synthetic classes generated by Mixin. Do not replace it with a plain
  instrumentation transformer: Mixin needs to generate classes for Kotlin inner
  classes and static handlers.
- Mixin handlers that use Kotlin lambdas must not capture the mixin instance in
  a lambda descriptor. Prefer loops or explicit classes for code that Mixin
  copies into target classes.

## Verification

- `./gradlew build` must pass.
- For protocol changes, test a legacy client against a current server through
  the proxy in offline mode.
